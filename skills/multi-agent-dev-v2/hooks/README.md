# Optional terminal-notification Hook

`task_terminal_notify.py` is an optional lifecycle companion to `scripts/notify_serverchan.py`. It is not registered or trusted by this package. Review `hooks.json.example`, merge only the required entries into the existing Hook configuration, replace the placeholder command paths, restart Codex, review/trust the Hook, then probe each event in a disposable test task.

The `PreToolUse` entry uses Codex's canonical `Bash` matcher and reads `tool_input.command` to register the active task. Registration is deliberately fail-closed: it accepts only a direct Python invocation of this package's exact `scripts/notify_serverchan.py` path with one `--register-active` and one safe `--task-id`; shell wrappers, compound commands, and extra notifier arguments do not register. It returns no stdout for transparent pass-through; this event does not support the shared `continue` field. `Stop` retries only persisted failed terminal intents; ordinary turn stops are no-ops. `Interrupt` and `SessionEnd` send a `stopped` compensation for an active task. The example sets the documented three-second maximum for those lifecycle events and gives `Stop` enough time for bounded notification retries. Unknown fields, event payloads, tool names, or untrusted/unloaded configuration mean the fallback is not active. Do not infer activation from configuration presence or the notifier's `registration_requested` response.

At task start, when this Hook has been verified, invoke the bundled notifier with `--register-active --task-id <safe-id>`. Use that same ID on the terminal notification; it is stored only as a SHA-256-derived local key and never sent to ServerChan. A route-less direct notification may omit the ID and still sends, but it cannot be deduplicated or tied to an interrupt fallback.

Never overwrite the user's Hook file, auto-trust this handler, or merge this sample without reviewing existing registrations. This package does not claim `HOOK_ENFORCED` until registration, retry, interruption, transparent-pass, and no-duplicate probes pass on the target Codex build.
